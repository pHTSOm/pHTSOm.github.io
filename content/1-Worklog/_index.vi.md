Đây là worklog trong 12 tuần qua của mình thuộc track DevOps nằm trong chương trình First Cloud Journey từ ngày 04/02/2026 đến 10/07/2026. 5 tuần đầu tiên của khóa học được dành để tìm hiểu các kiến thức nền tảng về kiến trúc AWS và vận hành cloud thực tế. 7 tuần cuối cùng được tập trung hoàn toàn vào việc triển khai dự án tốt nghiệp mang tên Project_Abstract — dự án được thực thi trên AWS sử dụng Amazon Bedrock (Nova Lite), Cognito, API Gateway, Lambda, DynamoDB, Terraform dạng modular, CI/CD pipeline (CodePipeline/CodeBuild), giám sát CloudWatch và CloudFront.

**Tuần 1:** [Kiến thức Mạng Căn bản, Các Thành phần Cơ bản trên AWS, IAM và CloudFormation](1.1-week1/)

**Tuần 2:** [Tính Sẵn sàng Cao, Auto Scaling, Serverless Lambda và Quản lý Bảo mật](1.2-week2/)

**Tuần 3:** [Khởi tạo EC2 Tự động, Ghi Log Cấp Hệ thống, SSM và Tách rời Kiến trúc Monolith](1.3-week3/)

**Tuần 4:** [Cơ sở Dữ liệu Quan hệ Managed, Chuyển đổi Dữ liệu với DMS, Aurora và Mở rộng CSDL](1.4-week4/)

**Tuần 5:** [DNS Toàn cầu với Route 53, Đóng gói Container với Docker và Điều phối ECS/Fargate](1.5-week5/)

**Tuần 6:** [Khởi động Dự án Capstone, Thiết kế Kiến trúc Serverless và Lựa chọn Mô hình Bedrock](1.6-week6/)

**Tuần 7:** [Thiết lập Môi trường Phát triển, Quy trình Git, Tích hợp Lambda Proxy và Thiết kế NoSQL](1.7-week7/)

**Tuần 8:** [Logic Backend AI Cốt lõi với Bedrock Nova Lite, Exponential Backoff và Unit Test với Pytest/Moto](1.8-week8/)

**Tuần 9:** [Xác thực Người dùng với Cognito Hosted UI và Bảo vệ các Route trên API Gateway](1.9-week9/)

**Tuần 10:** [Mã nguồn Hạ tầng Modular với Terraform và Cơ chế State Locking với S3/DynamoDB](1.10-week10/)

**Tuần 11:** [Tự động hóa CI/CD Pipeline (CodePipeline/CodeBuild), Quét Bảo mật và Giám sát với CloudWatch](1.11-week11/)

**Tuần 12:** [Thắt chặt Bảo mật Chuẩn CIS, Load Test API với Locust, Triển khai Static Frontend và Tài liệu Bàn giao](1.12-week12/)
